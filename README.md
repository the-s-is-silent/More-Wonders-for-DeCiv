# More Wonders for DeCiv
Reintroduce the race for wonders into DeCiv Redux with this collection of additional world wonders. This mod is specifically for Redux and will not work with the newer Deciv 2 fork (but many of the wonders present here were ported from Deciv 2 anyway).

This mod is very much a WIP and is open to contributions from anyone in the DeCiv community who has ideas they would like to see implemented.
